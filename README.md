# jthutto.com

Jarrett Hutto's portfolio, served by GitHub Pages as a static site (no build step).

- `index.html`: the whole site (home, robots row, robot pages).
- `turn/`: turntable frames for each robot at three sizes (`v13s`, `v13m`, `v13`), plus `meta-v13.js` with the crop and camera numbers.
- `img/`, `brand/`: Miata render, logos.
